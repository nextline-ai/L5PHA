약 3분

비용 한도부터, 안심하고 시작하세요.

처음 시작한다면 AWS New를 가장 권장합니다. Project별 월 비용 상한을 정하고, 한도에 도달하면 AWS가 리소스를 정지해 추가 AWS 비용을 제한합니다.

AWS New 시작하기 ↗
내 투자 서버에 월 AWS 비용 상한을 설정하세요.
  1. AWS New에서 L5PHA Project를 만들고 Sydney 리전을 확인합니다.
  2. AWS Settings의 Billing → Cost by project → Spend limit → Set limit에서 한도를 설정합니다.

Spend limit은 Paid Plan에서 제공합니다. 한도는 세전 AWS 비용에 적용되며 최소 설정액은 $20 또는 AWS가 제시한 예상 사용액 중 큰 값입니다.

비용 한도의 적용 범위

OpenAI·Gemini에 직접 지불하는 API 비용, 투자 원금·매매 손실은 AWS 한도에 포함되지 않습니다. 각 AI 제공자의 별도 비용 설정도 확인하세요.

한도 도달로 서버가 멈추면 L5PHA의 감시·주문 관리도 멈춥니다. 토스에 이미 접수된 주문과 보유 주식은 남으므로 토스 앱에서 확인하세요. 정지된 Project를 90일 동안 복구하지 않으면 AWS가 데이터를 삭제합니다.

Advanced features 전환은 권장하지 않습니다. 전환하면 Spend limit이 제거되며 되돌릴 수 없습니다. 이 설치 화면에서 전환을 진행하지 않습니다.

AWS 공식 비용 한도 안내 ↗

AWS New는 순차 제공 중입니다. 사용할 수 없는 계정은 기존 AWS로 설치할 수 있습니다. 현재 설치는 Sydney 리전을 지원합니다.

토스 API 준비하기 ↗
어떤 비용과 권한이 필요한가요?

서버·저장소·고정 IPv4·암호화 키·Secret·AI·웹검색 사용료가 발생합니다. AWS New에서도 설치 후 Spend limit을 직접 설정하고 유지해야 합니다. 무료나 월 고정 요금을 보장하지 않습니다.

AWS 로그인 정보는 AWS 화면에만 입력하세요. 빠른 설치는 OpenAI 또는 Gemini API를 사용합니다. AWS New는 Bedrock 교차 리전 추론을 지원하지 않으므로 제한을 해제하기 위해 Advanced features로 전환하지 마세요.

약 10–18분 · 자동 설치

AWS에서 한 번 승인하세요.

AWS New에서는 먼저 AWS Settings에서 설치할 L5PHA Project의 콘솔을 여세요. 아래 버튼으로 열리는 AWS 화면의 계정이 그 Project인지 확인한 뒤, 하단의 권한 생성 동의에 체크한 뒤 스택 생성을 누르세요.

내 AWS에 L5PHA 설치 ↗

서버·고정 IP·암호화 저장소·HTTPS·관리 화면을 자동으로 준비합니다. 설치만으로 실거래가 켜지지 않습니다.

Telegram에서 한 번 입력합니다. 설치 완료 후 1시간 동안 유효하며 다른 사람에게 보내지 마세요. 원본 코드는 이 브라우저에만 보관합니다.

이 탭을 유지하고 AWS의 상태가 CREATE_COMPLETE가 될 때까지 기다려주세요. AWS의 출력(Outputs) 탭에 접속 링크가 나타납니다.

실패했거나 25분 넘게 기다리고 있나요?

CREATE_FAILED 또는 ROLLBACK_COMPLETE라면 설치가 끝난 상태가 아닙니다. AWS 이벤트에서 실패한 항목을 확인하세요. 생성 권한·EC2 한도·선택 리전·인터넷 연결을 먼저 확인합니다.

같은 스택을 계속 새로 만들지 마세요. 실패한 스택과 남은 자원을 확인한 뒤 다시 시도하세요. 설치 중 입력한 증권사 키는 없습니다.

약 2분

Telegram에서 내 서버를 여세요.

  1. AWS 출력 탭에서 OpenTelegram 링크를 엽니다.
  2. 봇의 시작 버튼을 누르고 내 L5PHA 열기를 선택합니다.
  3. 이 페이지에서 복사한 최초 연결 코드를 붙여넣습니다.

이후부터는 봇 메뉴로 바로 접속합니다. 코드나 계좌 키를 Telegram 채팅에 보내지 마세요.

코드가 만료되거나 브라우저 기록을 지웠다면 AWS의 RecoveryActions에서 new-code로 재발급할 수 있습니다. 다른 사람이 Telegram에 먼저 들어오는 것만으로 내 서버를 소유할 수는 없습니다.

약 5–7분

이제 미니앱에서 마무리하세요.

  1. 토스 연결 · 표시된 고정 IP를 등록하고 API 키를 입력합니다.
  2. AI 선택 · 사용할 모델과 필요한 API 키를 연결합니다.
  3. 내 투자 기준 · 총 운용금액, 주문 상한, 하루 손실 한도와 전략을 정합니다.
  4. 운용 시작 · 관찰 분석으로 시작하거나 실거래 활성화를 직접 선택합니다.

DART·KRX 연결은 나중에 추가할 수 있습니다. 설정은 언제든 미니앱에서 바꿀 수 있습니다.

설치 후에는 컴퓨터를 켜둘 필요가 없습니다.
잠시 중단하거나 완전히 삭제하려면

먼저 미니앱에서 운용을 중단하고 토스에서 미체결을 확인하세요. 서버를 끄거나 삭제하는 것만으로 주문이 취소되거나 보유 주식이 매도되지는 않습니다.

완전 삭제는 AWS CloudFormation에서 해당 스택을 삭제합니다. 데이터 볼륨·Secret·암호화 키·일부 기록은 복구를 위해 남습니다. 출력 탭의 자원 ID를 저장한 뒤 보관 여부를 결정하고, AWS 청구 화면에서 잔여 비용을 확인하세요.

Telegram이 열리지 않으면 출력 탭의 RecoveryActions를 사용합니다. 중단은 pause, 로그인 폐기는 revoke-sessions, Telegram 연결 해제는 disconnect-telegram을 선택합니다. 계정 소유자만 AWS 권한으로 중단·세션 폐기·연결 코드 재발급을 진행할 수 있습니다.
