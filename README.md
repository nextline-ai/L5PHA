## 준비물 4가지

- **AWS 계정:** 투자 프로그램을 계속 실행할 공간입니다. **[AWS New](https://signin.aws.amazon.com/signup?request_type=register)를 가장 권장합니다.** Paid Plan에서 월 AWS 비용 한도를 직접 설정할 수 있습니다.
- **토스증권 계좌와 [Open API 키](https://developers.tossinvest.com/):** 프로그램이 내 계좌에 연결할 때 사용합니다.
- **OpenAI 또는 Gemini API 키:** AI를 사용하기 위한 연결용 키입니다. ChatGPT·Gemini 앱의 구독과는 별도입니다.
- **[Telegram 앱](https://telegram.org/):** 투자 현황을 보고 설정을 바꾸는 데 사용합니다.

## 이렇게 시작하세요

1. **[설치 화면](https://15.134.164.178/install)을 엽니다.** AWS New를 선택하고, 비용 한도 설정과 자동 설치 안내를 따라갑니다.
2. **Telegram을 연결합니다.** 설치가 끝나면 안내된 링크를 열고 내 화면에 최초 연결 코드를 입력합니다.
3. **내 투자 기준을 정합니다.** 토스·AI 키를 연결하고, 운용금액·손실 한도·전략을 선택합니다.

처음에는 관찰·분석부터 시작할 수 있습니다. **실거래는 직접 활성화해야 시작됩니다.** 설정은 나중에도 바꿀 수 있으며, DART·KRX 연결은 선택사항입니다.

## 비용과 운용

AWS 이용료와 AI API 요금이 각각 발생합니다. **AWS New의 비용 한도에는 외부 AI API 요금이나 투자 손실이 포함되지 않습니다.** AWS 한도로 서버가 멈추면 감시도 멈추지만, 토스의 주문과 보유 주식은 남습니다. 투자 수익은 보장되지 않습니다.

막히는 부분이 있으면 [자세한 설치·복구 안내](docs/installation.md)를 확인하세요. 연결 코드와 API 키는 미니앱의 입력란에만 입력하고, 채팅이나 공개 게시글에 올리지 마세요.
